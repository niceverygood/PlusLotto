## 3. 현장 회신으로 정리된 것 (9/23) / 남은 것

**정리됨**
- **최종 추출본 재수령 → 하지 않는다.** 현장: "과거 사이트 이전 관련해서는 보통 신결제가 없다고
  보시면 됩니다. 추가결제 같은 경우는 저희 측에서 처리할 예정이니 전달드린 자료만 입력해 주시면
  됩니다." → 델타 재적재 단계를 뺀다. 결제 쪽 잔여 위험은 현장이 수기로 흡수한다. 다만 결제가
  아닌 변경분(요일·탈퇴·정지)은 그대로 남으므로 §4로 옮긴다.
- **구전산 정리에 회원용 홈페이지가 포함된다.** 현장: "10/13 전산이 내려가면 회원용 홈페이지
  또한 삭제됩니다." → **도메인 연결은 10/13 이전에 반드시 끝나야 한다.** 10/8~9 연결 일정 유지.
- **홈페이지 자료 9/30, 도메인 소유권 이전 10/7** — 현장 확답.
- **대조표 → 받은 날짜에 검수** — 현장 확답. 저희가 먼저 보내야 검수가 시작된다.
- **88로또 10/12 이관 → 10/13 첫 발송** — 현장 승인("말씀주신 대로 진행").
- **프리미엄 자료** — 기한(10/2 최선, 10/6 마지노선) 내 전달 확답.

## 4. 남은 위험 — 8/21~10/5 사이 비결제 변경분

최종 추출본을 받지 않기로 했으므로, 원본 추출일(815 8/31 / 인포·일행 8/21) 이후 구전산에서 일어난
변경 중 **결제가 아닌 것**은 신전산에 없다. 결제는 현장이 수기로 흡수하지만 아래는 흡수 대상이 아니다.

| 변경 | 신전산에서 벌어지는 일 | 크기 |
|---|---|---|
| 조합 발송요일 변경 | 회원이 원하지 않는 요일에 조합문자를 받는다 | 민원 가벼움 |
| 탈퇴·수신거부 | **탈퇴한 사람에게 조합문자가 나간다** | 민원 무거움 |
| 정지 | 정지된 회원에게 조합문자가 나간다 | 민원 무거움 |

완화책: 현장에 **8/21(인포·일행)·8/31(815) 이후 탈퇴·정지 회원 명단만** 요청한다. 전체 재추출이
아니라 목록 한 장이면 되고, 받는 즉시 해당 회원을 발송 대상에서 빼면 무거운 쪽 두 가지가 막힌다.
요일 변경은 회원이 알려주면 화면에서 바로 고칠 수 있으므로 별도 조치를 두지 않는다.
